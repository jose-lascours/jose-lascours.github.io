# jose-lascours.github.io

Portfolio personal de Jose Lascours, desarrollador backend, publicado en
https://jose-lascours.github.io/.

Es un sitio estático en HTML, CSS y JavaScript, sin frameworks ni paso de
build, con tema claro y oscuro y versión en español e inglés.

## Ejecutar en local

```bash
python -m http.server
```

Después abrí http://localhost:8000.

## Tests

Requieren Node.js 18 o superior y no usan dependencias externas.

```bash
node --test
```
